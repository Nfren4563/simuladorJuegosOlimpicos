## Descripción

Este proyecto es un simulador de Juegos Olímpicos desarrollado en Java.

El programa permite registrar eventos deportivos y participantes. Después puede seleccionar aleatoriamente a los ganadores de las medallas de oro, plata y bronce.

También puede mostrar informes y un ranking de países.

## Funciones principales

- Registrar eventos deportivos.
- Registrar participantes.
- Indicar el país de cada participante.
- Simular los resultados de un evento.
- Asignar medallas de oro, plata y bronce.
- Crear informes de los eventos.
- Mostrar un ranking de países.

## Requisitos

- Java JDK 23.
- Apache Maven.
- Una terminal o un IDE compatible con Maven.

## Cómo descargarlo

```bash
git clone https://github.com/Nfren4563/simuladorJuegosOlimpicos.git
cd simuladorJuegosOlimpicos/juegosOlimpicos
```

## Cómo compilarlo

```bash
mvn compile
```

## Cómo ejecutarlo

```bash
java -cp target/classes org.example.Main
```

También puedes abrir el proyecto en IntelliJ IDEA y ejecutar el archivo `Main.java`.

## Opciones del programa

El menú contiene las siguientes opciones:

1. Registrar un evento.
2. Registrar participantes.
3. Simular un evento.
4. Crear un informe.
5. Mostrar el ranking de países.
6. Salir.

Para simular un evento se necesitan al menos tres participantes.
